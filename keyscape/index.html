Overview

Keyscape Homes is a full-stack Airbnb-style shortlet booking platform built for the Lagos luxury rental market. Guests can browse verified properties, pick dates on an interactive calendar, and confirm bookings directly via WhatsApp — all in a few taps.

Hosts manage their listings through a dedicated portal where they can update availability, block dates on a calendar, edit property details, and track enquiries. Authentication uses Google Sign-In via Firebase so onboarding is instant and secure.

What's Built

  • Full guest booking flow — browse, dates, confirm
  • Interactive calendar — guests pick check-in & out
  • Host portal — edit listings, block calendar dates
  • Google Sign-In via Firebase Auth
  • WhatsApp booking integration — instant host contact
  • Firebase Firestore — real-time listings & bookings
  • Property search by location or name
  • Host listing submission & approval flow
  • Mobile-first responsive design
