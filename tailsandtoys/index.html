Overview

Tails & Toys LLC is a fully functional e-commerce store built for a real cat accessories brand. The site handles everything from browsing a live product catalogue to adding items to a persistent cart and proceeding to checkout — all backed by Firebase for real-time data and authentication.

An admin portal lets the store owner manage products, update stock, and track orders without touching code. Stripe integration is currently in progress to complete the payment flow.

What's Built

  • Live product catalogue with category filters
  • Cart system with persistent storage
  • Firebase backend — products, orders & auth
  • Full admin portal — manage products & orders
  • Instagram DM integration via link
  • Responsive mobile-first design
  • Stripe checkout — in progress
