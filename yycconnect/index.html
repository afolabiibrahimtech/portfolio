Overview

YYC Connect is a settlement super-app built to help newcomers — students, workers, permanent residents, and refugees — get oriented in Calgary fast. It brings housing, jobs, events, weather, and local resources into one personalized dashboard.

The housing module is powered by my own Porchlight platform, and job search aggregates listings across Indeed, LinkedIn, and Glassdoor using the jSearch API, with the Anthropic API helping process and surface the most relevant results. The entire backend runs on Cloudflare Workers, with Firebase handling authentication and data.

What's Built

  • Google & email sign-up with guided onboarding
  • Job search across Indeed, LinkedIn & Glassdoor
  • Housing search powered by Porchlight
  • Live Calgary weather & winter survival guide
  • Local events & meetup discovery
  • Settlement progress tracker & task checklist
  • Full admin CMS — users, listings, jobs, events
  • Built on Cloudflare Workers
